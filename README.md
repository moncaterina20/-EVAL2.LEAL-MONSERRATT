# Rediseño Home Municipalidad de Cholchol

Trabajo academico de Desarrollo Frontend. Se hizo una nueva pagina de inicio para la Municipalidad de Cholchol usando Bootstrap, CSS y JavaScript.

## Archivos principales

```text
cholchol_home/
  index.html
  css/styles.css
  js/app.js
  assets/cholchol-hero.png
  docs/informe_base.md
  docs/informe_base.doc
```

## Funciones agregadas

- Menu responsivo con Bootstrap.
- Boton para cambiar contraste.
- Buscador de tramites.
- Boton para marcar tramites como favoritos.
- Boton para agregar una noticia de ejemplo.
- Formulario de contacto con validacion en tiempo real.
- JavaScript separado en funciones simples para mostrar contenido, validar el formulario y manejar eventos.

## Criterios

- CE1: eventos `click`, `input`, `blur` y `submit`.
- CE2: validacion de nombre, correo y mensaje.
- CE3: se agregan y actualizan elementos usando JavaScript.
- CE4: uso de Bootstrap, diseño responsivo y elementos basicos de accesibilidad.
- CE5 y CE6: colores, tarjetas, botones y separacion visual.
- CE7 y CE8: archivos separados por carpeta y uso de `DOMContentLoaded`.

## Como abrir

Abrir el archivo `index.html` en el navegador.
